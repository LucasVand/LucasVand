# Hey, I'm Lucas 👋

I like building tools that make difficult things feel simple, from developer tooling and language tools to GPU-accelerated simulations and small apps. Always trying to learn more and explore.

## What I'm working with

- **Rust** for systems programming, developer tools, compilers, and graphics
- **wgpu / WGSL** for GPU rendering and compute
- **TypeScript** for web applications
- **Swift** for iOS projects
- **C and C++** for systems and embedded projects
